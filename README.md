# 🤖 Discord TTS Voice Bot

Bot Discord đọc tin nhắn bằng tiếng Việt trong voice channel.

## ✨ Tính năng

- 🗣️ Text-to-Speech tiếng Việt
- 🔊 Tự động đọc tin nhắn khi ở voice channel
- 🎯 Điều khiển bằng lệnh đơn giản

## 📋 Lệnh

- `!join` - Bot vào voice channel
- `!leave` - Bot rời voice channel  
- `!test` - Kiểm tra trạng thái bot
- `!tts test` - Test audio trực tiếp
- Gõ tin nhắn bất kỳ - Bot đọc to (khi đã join)

## 💻 Setup

1. Clone repository
2. `npm install`
3. Tạo file `.env` với `DISCORD_TOKEN=your_token`
4. `npm start`
